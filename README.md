# Rastreador de Finanças Pessoais

Sistema de controle financeiro pessoal desenvolvido em Python.

## Funcionalidades

- Cadastro de receitas
- Cadastro de despesas
- Cálculo de saldo
- Relatórios financeiros
- Estrutura modular
